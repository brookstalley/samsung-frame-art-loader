## What would bite you

**The Status checkboxes are a derived view.** `views_enabled: true`, so marking a
chunk `[x]` by hand is wrong and `regen-views` will undo it. Write a tagged
change-log entry (`<!-- prawduct: chunks=10 | status=shipped | scope=v1-build -->`)
and run `prawduct-hook regen-views`. I got this wrong on 09 and the Critic caught
it; the entry for 09 is there now as a template.

**Prose that ships to a caller is where this chunk kept failing.** Three of the
four review rounds were tool tips, a docstring, or a record describing behaviour
the code no longer had — never the code itself. When Chunk 10 changes a refusal or
a precondition, grep `mcp/tools.py` as part of the same change, not after. The
learning is in `learnings.md` with its evidence in the new `learnings-detail.md`.

**A guard against drift is untested until you break it.** Revert the fix, run the
suite, confirm it goes red. My first version of the tip guard passed against the
exact defect it was written for.
